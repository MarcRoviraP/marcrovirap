## 🤖 AI-Driven Workflow (Productivity Boost)

Optimizo mi flujo de trabajo utilizando un ecosistema avanzado de **Agentes de IA**, lo que me permite acelerar los tiempos de desarrollo manteniendo un estándar de calidad riguroso:
- 🌌 **Antigravity + gentle-ai**: Mi asistente cognitivo principal integrado con el [ecosistema gentle-ai de Gentleman Programming](https://github.com/Gentleman-Programming/gentle-ai), ideal para el diseño de arquitectura y refactorización.
- 🧠 **Engram**: Gestión de memoria persistente que retiene decisiones arquitectónicas previas y convenciones del proyecto para evitar la pérdida de contexto.
- 💻 **Geminicli**: Interacción ágil mediante terminal para scripting y automatizaciones rápidas.
